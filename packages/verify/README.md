# @use-africa-pay/verify

Server-side helpers for verifying African payment providers.  
This package makes it easy to:

- Verify payment status directly from provider APIs
- Validate webhook signatures securely
- Get a unified, type-safe response across providers

Supported providers:

- Paystack
- Flutterwave
- Monnify
- Remita

---

## Installation

```bash
npm install @use-africa-pay/verify
```
